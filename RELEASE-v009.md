# CODM-2M-v009

- Prompts for the CODM directory on first startup.
- Saves the directory in settings.ini next to the application.
- Reuses valid saved settings without prompting.
- Adds a CODM directory button in the top right; changing it scans the new directory.
- Invalid or unavailable saved directories prompt again.

Extract the ZIP to a writable folder and launch CODM-2M-v009.exe.
